SCULPT WING 0.6.8 — EDITOR, EQ, PAN E RTA · MAC M1

Questo ZIP aggiorna i sorgenti del repository Sculpt-Wing 0.6.7 già caricato.
Il pacchetto Mac ARM64 viene creato dal workflow GitHub dopo il caricamento.

NOVITÀ

• Cambiando canale con l’editor aperto rimane lo stesso modulo: EQ, Dinamica,
  Mandate e le altre sezioni. Sono conservate le sottoviste compatibili.
• Apertura e cambio canale ricostruiscono il pannello una sola volta.
  Il log delle macro non provoca un aggiornamento globale di tutte le strip.
• Le bande WING EQ seguono il puntatore anche quando il grafico è ridimensionato.
  Afferrare il punto non cambia i valori. Maiusc dà una regolazione più fine.
• Pan sopra il fader di ogni strip audio. Trascina in orizzontale o in verticale;
  doppio clic = centro C. Il gesto si annulla con Cmd+Z.
• In SOF, pan della mandata CH/AUX. LINK indica che segue il pan del canale:
  disattiva Pan link nell’editor Mandate per una regolazione indipendente.
• RTA da dati reali WING nella pagina Meter / RTA. Spettro a 120 bande, sorgente
  e tap effettivi, scala relativa. Senza banco il grafico resta vuoto.
• L’RTA WING è globale: un indice numerico privo di mappatura verificabile viene
  mostrato come Sorgente WING #N. Non viene attribuito arbitrariamente al canale.
  L’overlay EQ richiede una sorgente verificabile; altrimenti usa RTA banco.

CARICARE SU GITHUB

1. Estrai Sculpt-Wing-0.6.8-Aggiornamento-Mac-M1.zip.
2. Apri mrgianluca990-bit/Sculpt-Wing, ramo main.
3. Add file → Upload files: carica il CONTENUTO estratto mantenendo le cartelle
   dist, native, desktop, docs, tests e i file alla radice. Conserva gli altri
   file del repository; questo ZIP contiene soltanto aggiornamenti e aggiunte.
4. Commit changes. Il workflow Build Sculpt Wing - Mac M1 parte automaticamente.
5. Actions → esecuzione completata → artifact Sculpt-Wing-Mac-M1.
6. Estrai lo ZIP di GitHub e poi Sculpt-Wing-0.6.8-mac-arm64.zip.
7. Chiudi la vecchia app e sostituiscila con Sculpt Wing.app in Applicazioni.

La cartella .github può essere nascosta dal Finder: Cmd + Shift + . la mostra.
Il workflow deve stare in .github/workflows/build-desktop.yml. È incluso nello
ZIP per ripristinarlo se necessario; non va aggiunto un livello di cartella.

USO

• Editor: clic sul nome di un canale. Rinomina porta al campo Nome; vuoto =
  nome standard. L’editor occupa la riga opposta.
• Fader: afferra la testa; doppio clic = 0 dB. Pan: doppio clic = centro C.
• DCA: nella riga superiore, ancorabili. Non hanno un pan audio.
• Cmd+Z annulla; Maiusc+Cmd+Z ripristina. Un gesto equivale a una operazione.
• WING: collegamento in lettura, poi Attiva controllo per modificare i valori.
• Meter / RTA: controlla la sorgente effettiva prima di interpretare lo spettro.
• Import PDF: modifica e controlla l’anteprima prima di applicare la channel list.
• OSC / Sculpt Show: configurazione e invio direttamente dalla shell desktop.
